# 最新回合重写真实验收预登记

目标：验证“重写最新回合”在真实默认模型上是否既能安全交付，也能让一次性纠错实际改善或保持叙事语义，而不只是通过自动测试。

- 模型：`deepseek-v4.1-flash`，Pi `xhigh`（产品口径 max）。
- 路径：默认 `PiRunner` 完整回合，不启用 Public Continuity Card、语义 reviewer 或场景分离实验。
- 案例：事实/时间因果、NPC 知情边界、玩家重大决定，各自独立重复 3 次，共 9 组、18 次最终生成。
- 每组：从冻结 workspace 生成一个普通回合；随后经正式 `retryLatestTurn` 接口带一次性纠错重写。两步共用同一 Orchestrator；不手工编辑产物，不补跑失败样本。
- 格式处理：保留产品默认 `PI_MAX_ATTEMPTS=2`，允许 Harness 对非法结构作一次有限自修复。记录最终技术结果，不把首次格式错误与最终交付混为一谈。
- 安全检查：重写必须保持原输入和 `turnId`、历史长度不增加、较早历史不变；失败必须保留原回合；若存在随机绑定必须复用。
- 语义检查：按冻结案例 checklist 人工逐项核对原文与重写文。重写若未修复指定问题，或新增事实捏造、知情泄漏、替玩家决定、因果倒置，记硬失败。

晋级门槛：9/9 重写技术成功；至少 8/9 重写文本通过全部语义检查；新增硬错误为 0。未达门槛时不增加无限审稿、重试或模型专属规则，先区分模型未服从纠错、上下文缺失或实现错误。
