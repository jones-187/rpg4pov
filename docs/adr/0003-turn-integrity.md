# 回合一致提交与先定候选后抽样

2026-09-19。已接受；真实叙事质量待重新验收。正文、必要状态变更与随机审计共同决定一个回合是否成功：任何解析、替换或随机确认失败都不得写成功标记，交由既有快照恢复。明确无状态变化使用 `=== NO CHANGES ===`，不能把缺失文件当作无变化。

替代 ADR 0001 中“先暴露随机池、再事后核对且不一致只告警”的策略。模型先写 `turn/roll-request.json` 固定候选，程序验证整批后抽样，随后冷启动生成只接收绑定结果而不接收样本；生成重试复用结果，禁止修改请求。普通无风险回合不增加阶段。有风险回合多一次模型调用，这是结果约束优先于时延的取舍。自然语言是否真正遵守结果仍需行为验收，确认行和审计正确不能替代语义验证。

默认不发布未提交正文；`PI_UNCOMMITTED_PREVIEW=1` 仅保留为显式实验开关。回滚不能撤销玩家已经读到的信息，因而不能靠前端撤回预览保证故事体验。

可选实验 `PiRunner({ experimentalSceneSeparation: true })` 先产出可观察事件、内部状态更新和交互状态，再只向叙事阶段提供可见资料；叙事阶段只允许写正文。默认路径不启用；同场景实测质量与耗时后才决定推广。事件列表仍由模型从私有资料中筛选，因此这是减少暴露的接口约束，并非语义泄漏的形式证明。

初始化“missing or stale”原先同时覆盖内容校验失败；现分开新鲜度与内容校验，并将明确失败原因反馈给下一次概念生成。旧 A/B 原始临时文件已不存在，修复可复现缺陷不等于证明旧失败案例根因已解决。
