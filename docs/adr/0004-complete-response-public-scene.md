# 完整响应由程序提交，公开场景明确交接

2026-09-20 真实验收确认模型可以正常退出且输出小说，却完全不调用 write；开场按 Markdown 标题摘录上下文还会漏掉清晨并混入“不知道”的秘密。因此普通 Pi 回合与实验分离阶段关闭模型工具，接收单个有明确类型的完整 JSON 响应，由程序统一校验、写入候选并复用现有提交/回滚；保留先请求随机、再生成的顺序，不以裸正文或磁盘残留兜底。

开场只从 player.md 的独立 Public Scene JSON 获取时间、地点、声音、已知事实和可见人物，缺少或格式错误时拒绝概念 Bundle，不再回退到自由文本摘录。实验叙事接收本回合计划中的 Public Scene，不能复用开场旧时点。代价是模型必须遵守结构化响应，旧的非结构化初始化材料不能直接复用到新开场阶段；换来程序掌握写入顺序与明确的数据区域隔离，但这仍不构成语义保密证明。初始化工具写盘路径暂保留，普通回合取消未提交预览和基于磁盘产物的早退。

后续真实复现进一步发现：把逐行 APPEND/REPLACE 方言嵌在 JSON 字符串里，仍会因多行内容表达失败而拒绝完整响应。因此默认 stateUpdate 也改为显式 sections/rolls 对象，操作用 kind/text/from/to 表达；复用既有路径校验与精确替换，不放宽旧 Markdown 解析规则，旧格式仅作严格兼容。
