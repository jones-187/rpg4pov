## 当前决策（优先于下方历史下一步）

### 当前待办：语义连续性优先

- **核心阻塞**：模型生成的正文、事实、角色认知、时间、承诺与持久状态可能前后矛盾；这会直接破坏沉浸感，优先级高于格式首次成功率。
- **格式待办（暂缓）**：后续验证网关严格 JSON Schema，并评估 Harness 有限修正后的最终成功率；当前已有严格校验、零写入错误反馈、有限重试与失败回滚，格式问题不作为下一阶段主线。
- **下一阶段候选（尚未批准实施）**：依据[LLM互动叙事架构调研](research/2026-09-25-llm-narrative-architecture.md)，不建设完整“语义权威层”或硬状态机；先用真实失败案例 A/B 验证“薄事实底座 + 模型主导叙事”。底座只保存自然语言事件及来源、时间、见证者/可见性和因果引用，并机械保护玩家输入、时间锚点与骰子结果；人物动机、关系含义、推断和剧情走向继续交给模型。
- **验收标准**：同一冻结连续故事中，正文与事件证据一致；未发生的玩家行动不落账；NPC获得的信息可追溯到可见事件；玩家未确认的重大决定不转为事实；时间变化具有可追溯因果，同时盲评叙事是否变僵。格式成功与语义成功分开计分。
